# ARCHIVES.md — the receipt vault

> Every scrub-vulnerable primary this project cites, with its archive URL. The rule
> (SOURCING.md §2, naming policy §5): **archive before you point.** The moment this site
> shares publicly, every live URL it cites becomes a scrub target — the About pages get
> rewritten, the tweets get deleted, the clips get pulled. This file is the insurance.
>
> Convention: prefer the OLDEST clean snapshot (contemporaneous archives predate any
> dispute) + one fresh snapshot proving the source was still live when we published.
> When a source is scrubbed after we cite it, ADD the scrub date here — the scrub itself
> becomes evidence (see PFIR's rename, corkboard P-18).

## The standing rule

New quote or citation on the site → its archive line lands HERE in the same session, or the
citation carries a verify badge until it does. Wayback SPN: `web.archive.org/save/{url}`
(rate-limited; ~12s spacing; the availability/CDX API 503s without a browser User-Agent).
For X/Twitter: check twitter.com CDX history first — contemporaneous snapshots usually exist
and beat fresh ones.
